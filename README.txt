MANA FINANCE - EMAIL SIGNATURE ASSETS
=====================================

Upload every file in this folder to your website so that it is reachable at:

    https://www.manafinance.com.au/email/<filename>

e.g. https://www.manafinance.com.au/email/badge-approval.png

FILES
-----
  jack-neale.png        headshot (circular, transparent corners)  160x160  (displayed at 80x80)
  badge-approval.png    "100% Approval Rate"  268x56  (displayed at 134x28)
  badge-banks.png       "70+ Banks"           162x56  (displayed at  81x28)
  badge-book.png        "Book A Call"         172x56  (displayed at  86x28)
  icon-web.png          globe icon             44x44  (displayed at  22x22)
  icon-phone.png        mobile icon            44x44  (displayed at  22x22)
  icon-email.png        envelope icon          44x44  (displayed at  22x22)

Every image is stored at twice its display size so it stays sharp on
retina / high-DPI screens. Do not rename the files - the signature HTML
refers to them by these exact names.

CHECK BEFORE GOING LIVE
-----------------------
Paste each URL into a browser. If the image appears, you are done. If you
get a 404 or a login page, the file is not public and the signature will
show a broken image for your recipients.

WHY THIS MATTERS
----------------
Images referenced by an https:// URL stay URLs - they never become email
attachments. That is the whole reason WiseStamp behaved the way it did,
and this folder reproduces it without the subscription.
